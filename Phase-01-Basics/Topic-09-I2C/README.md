# Topic 09: I²C

**Week 3** · Your first real sensor over a bus. I²C is also the bus the BNO085 IMU uses if you explore it later.

## Why I²C for sensors

From Topic 08: I²C trades speed for simplicity. It needs just 2 signal wires (plus power and ground), and many devices share them because each has an **address**. Sensors send small amounts of data, so that is the right tradeoff.

## The two wires

| Signal | Meaning |
| ------ | ------- |
| **SDA** | Serial Data: shared by every device on the bus |
| **SCL** | Serial Clock: generated by the master (the ESP32-S3) |

On the Xiao in this repo: **SDA = D4, SCL = D5**.

## Pull-up resistors

I²C lines are "open drain": devices only pull them LOW, and resistors pull them back HIGH. Most breakout boards include the pull-ups. If a bare chip does not work, add 4.7 kΩ-10 kΩ from SDA and SCL to 3.3 V.

## Addresses

Every device has a fixed 7-bit address (e.g. `0x38` for an AHT20, `0x76` or `0x77` for a BME280). The master sends the address first. Every device hears it, but only the matching one answers.

## Scanning the bus

A **bus scanner** asks every possible address "are you there?" It is the standard first step with any new I²C device, and it confirms your wiring before you write any sensor code:

```cpp
Wire.begin();
for (uint8_t addr = 1; addr < 127; addr++) {
  Wire.beginTransmission(addr);
  if (Wire.endTransmission() == 0) {
    Serial.printf("Found device at 0x%02X\n", addr);
  }
}
```

If nothing is found, it is almost always wiring (SDA/SCL swapped, no power, no common ground) or missing pull-ups, not your code.

## Reading a sensor

Libraries hide the register details. Example with an AHT20-style temperature/humidity sensor (a BME280 follows the same pattern with a different library):

```ini
; platformio.ini
lib_deps =
    adafruit/Adafruit AHTX0
```

```cpp
#include <Adafruit_AHTX0.h>

Adafruit_AHTX0 aht;

void setup() {
  Serial.begin(115200);
  if (!aht.begin()) {
    Serial.println("Sensor not found: check wiring");
  }
}

void loop() {
  sensors_event_t humidity, temp;
  aht.getEvent(&humidity, &temp);
  Serial.printf("Temp: %.1f C  Humidity: %.1f %%\n",
                temp.temperature, humidity.relative_humidity);
  delay(2000);
}
```

> **Not I²C:** your DHT11 is a single-wire sensor with its own timing protocol. It gets its own topic next (Topic 10). Do not put it on SDA/SCL.

> **No I²C sensor yet?** Run the scanner anyway on any I²C device you own (the BNO085 works), or order a cheap AHT20/BME280 (see `hardware/README.md`).
